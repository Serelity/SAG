# 00 - 环境与部署记录

本文记录当前 Windows + WSL2 + Docker Desktop 部署 RAGFlow 的过程和关键结论。

## 主机环境

| 项目 | 当前值 |
| --- | --- |
| Windows 用户 | `xiang` |
| WSL 发行版 | `RAGFlow-Ubuntu` |
| Ubuntu 版本 | `Ubuntu 24.04.4 LTS` |
| WSL 版本 | `2.7.10.0` |
| WSL 内核 | `6.18.33.2-2` |
| 架构 | `x86_64` |
| Docker Desktop | `4.55.0` |
| Docker Engine | `29.1.3` |
| Docker Compose | `v2.40.3-desktop.1` |

## WSL 资源配置

Windows 用户目录下的 `.wslconfig`：

```ini
[wsl2]
memory=16GB
processors=10
swap=8GB
localhostForwarding=true
```

验证命令：

```powershell
wsl -d RAGFlow-Ubuntu -- bash -lc "free -h; nproc"
```

已确认：

- 内存约 `15Gi`
- Swap `8.0Gi`
- CPU 核数 `10`

## 数据目录

| 内容 | 路径 |
| --- | --- |
| Ubuntu VHD | `D:\WSL\RAGFlow-Ubuntu\ext4.vhdx` |
| Docker Desktop 数据目录 | `D:\DockerData\DockerDesktopWSL` |
| RAGFlow Docker 部署副本 | `~/deploy/ragflow-v0.26.4` |

说明：

- `G:\RAG\ragflow-main` 是上游源码参考快照，不在学习仓库中直接修改。
- `~/deploy/ragflow-v0.26.4` 是实际运行用的 Docker 部署副本。

## RAGFlow 版本与运行模式

| 配置项 | 当前值 |
| --- | --- |
| RAGFlow 镜像 | `infiniflow/ragflow:v0.26.4` |
| 运行模式 | CPU |
| 文档引擎 | Elasticsearch |
| Web 端口 | `80 -> http://localhost` |
| API 端口 | `9380` |
| MySQL 暴露端口 | `13306 -> 3306` |

关键 `.env` 配置：

```text
DOC_ENGINE=${DOC_ENGINE:-elasticsearch}
DEVICE=${DEVICE:-cpu}
SVR_WEB_HTTP_PORT=80
RAGFLOW_IMAGE=infiniflow/ragflow:v0.26.4
MYSQL_PORT=3306
EXPOSE_MYSQL_PORT=13306
```

## 启动命令

从 Windows PowerShell 启动：

```powershell
wsl -d RAGFlow-Ubuntu -- bash -lc "cd ~/deploy/ragflow-v0.26.4 && docker compose -f docker-compose.yml start"
```

如果是首次启动或需要创建容器：

```powershell
wsl -d RAGFlow-Ubuntu -- bash -lc "cd ~/deploy/ragflow-v0.26.4 && docker compose -f docker-compose.yml up -d"
```

## 状态检查

```powershell
wsl -d RAGFlow-Ubuntu -- bash -lc "cd ~/deploy/ragflow-v0.26.4 && docker compose -f docker-compose.yml ps"
```

预期服务：

- `mysql`
- `redis`
- `minio`
- `es01`
- `ragflow-cpu`

其中 `mysql`、`redis`、`minio`、`es01` 应显示 `healthy`，`ragflow-cpu` 应显示 `Up`。

## Web/API 验证

Web：

```powershell
Invoke-WebRequest -UseBasicParsing http://localhost -TimeoutSec 30 | Select-Object StatusCode
```

预期：

```text
StatusCode
----------
       200
```

API 端口：

```powershell
Test-NetConnection localhost -Port 9380 | Select-Object ComputerName,RemotePort,TcpTestSucceeded
```

预期：

```text
TcpTestSucceeded
----------------
True
```

## 安全停止

只停止容器，保留数据：

```powershell
wsl -d RAGFlow-Ubuntu -- bash -lc "cd ~/deploy/ragflow-v0.26.4 && docker compose -f docker-compose.yml stop"
```

不要执行：

```powershell
docker compose down -v
```

原因：`-v` 会删除 Docker volume，可能导致数据库、对象存储、索引数据丢失。
