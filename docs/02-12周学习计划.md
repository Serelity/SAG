# 02 - 12 周学习计划

目标投入：每周 15 小时以上。建议节奏是每周 5 天，每天 2-3 小时，周末做一次复盘。

## 总体节奏

| 阶段 | 周数 | 目标 |
| --- | --- | --- |
| 第一阶段 | 第 1-2 周 | 稳定部署、理解服务组成、建立记录习惯 |
| 第二阶段 | 第 3-5 周 | 阅读 Web/API/数据库主线 |
| 第三阶段 | 第 6-8 周 | 阅读 RAG、文档解析、检索链路 |
| 第四阶段 | 第 9-10 周 | 模型接入、Embedding、问答闭环实验 |
| 第五阶段 | 第 11-12 周 | 做源码级小实验，整理成果上传 GitHub |

## 第 1 周：环境、部署与启动链路

目标：

- 熟悉 Windows + WSL2 + Docker Desktop 的运行边界。
- 能独立启动、停止、检查 RAGFlow。
- 建立学习日志模板。

任务：

- [x] 完成 WSL2、Ubuntu、Docker Desktop。
- [x] 完成 RAGFlow Docker 部署。
- [x] 记录端口冲突和修复过程。
- [ ] 梳理 `docker-compose.yml` 与 `docker-compose-base.yml` 的服务关系。
- [ ] 画出 5 个核心容器之间的数据流。

产出：

- `docs/00-环境与部署记录.md`
- `docs/04-排障记录.md`
- `labs/week-01.md`

## 第 2 周：配置文件与容器内部结构

目标：

- 理解 `.env`、`service_conf.yaml.template`、容器启动脚本的作用。
- 知道 RAGFlow 的日志位置和排障入口。

任务：

- [ ] 阅读 `docker/.env` 中端口、密码、镜像、文档引擎配置。
- [ ] 阅读 `docker/docker-compose.yml` 中 `ragflow-cpu` 服务。
- [ ] 阅读 `docker/docker-compose-base.yml` 中 MySQL、Redis、MinIO、Elasticsearch 服务。
- [ ] 记录启动日志里 “ready” 相关关键行。
- [ ] 总结为什么不能随便使用 `docker compose down -v`。

产出：

- 一篇部署结构笔记。
- 一份常用命令清单。

## 第 3 周：Web 前端入口

目标：

- 理解前端项目如何组织页面、路由、请求和状态。

任务：

- [ ] 阅读 `web/package.json`，理解 `dev`、`build`、`test`、`lint` 脚本。
- [ ] 阅读 `web/src` 目录结构。
- [ ] 找到登录、模型供应商、知识库页面的前端入口。
- [ ] 找到前端请求后端 API 的封装位置。

产出：

- 一张前端目录结构说明。
- 一篇“RAGFlow 前端如何调用后端”的笔记。

## 第 4 周：API 与数据库模型

目标：

- 理解后端 API 如何接收请求、校验参数、操作数据库。

任务：

- [ ] 阅读 `api/apps` 目录，找到模型配置、知识库、文档相关 API。
- [ ] 阅读 `api/db/db_models.py`，理解主要数据表。
- [ ] 阅读 `api/db/services`，理解服务层封装。
- [ ] 重点跟踪“添加模型供应商”的后端逻辑。

产出：

- 一篇 API 分层笔记。
- 一份主要数据库模型清单。

## 第 5 周：用户、租户、模型配置

目标：

- 理解 RAGFlow 为什么需要先配置 LLM 和 Embedding。
- 理解 `OpenAI-API-Compatible` 的源码调用方式。

任务：

- [ ] 阅读 `api/apps/llm_app.py`。
- [ ] 阅读 `api/db/services/tenant_llm_service.py`。
- [ ] 阅读 `rag/llm/chat_model.py`。
- [ ] 阅读 `rag/llm/embedding_model.py`。
- [ ] 记录 `chat.completions.create` 与 `embeddings.create` 的调用位置。

产出：

- 一篇模型配置源码导读。
- 一份“RAGFlow 模型供应商排障检查表”。

## 第 6 周：文档上传与解析入口

目标：

- 理解文档进入系统后的处理流程。

任务：

- [ ] 找到文件上传 API。
- [ ] 跟踪文件保存到 MinIO 的逻辑。
- [ ] 找到文档解析任务的创建位置。
- [ ] 阅读 `deepdoc/` 的主要目录。

产出：

- 一篇“文档上传到解析任务”的流程笔记。

## 第 7 周：文本切分与 Chunk

目标：

- 理解文档如何被切成可检索片段。

任务：

- [ ] 找到 chunk 相关 API 和数据库模型。
- [ ] 阅读 `rag/` 中与切分、解析、token 相关的代码。
- [ ] 记录不同文件类型的解析差异。

产出：

- 一篇 Chunk 机制笔记。

## 第 8 周：检索与索引

目标：

- 理解 Elasticsearch 在 RAGFlow 里的角色。

任务：

- [ ] 找到写入 Elasticsearch 的代码路径。
- [ ] 找到用户提问时检索 chunk 的代码路径。
- [ ] 记录关键词检索、向量检索、混合检索的差异。

产出：

- 一篇检索链路笔记。

## 第 9 周：Embedding 模型实验

目标：

- 配置一个可用的 Embedding 模型，完成文档向量化。

任务：

- [ ] 选择一个支持 `/v1/embeddings` 的供应商。
- [ ] 在 RAGFlow 中添加 Embedding 模型。
- [ ] 创建一个测试知识库。
- [ ] 上传小文档并观察解析、切分、索引。

产出：

- 一份模型配置记录。
- 一份文档解析实验记录。

## 第 10 周：LLM 问答闭环实验

目标：

任务：

- [ ] 选择一个支持 `/v1/chat/completions` 的供应商。

产出：

- 一篇“从提问到答案”的链路分析。

## 第 11 周：源码级小实验

目标：

- 做一个低风险源码级学习实验。

候选实验：

- 在日志中增加某个请求链路的关键字段。
- 修改前端某个页面的中文说明。
- 为模型配置失败增加更明确的错误记录。
- 写一个最小测试，验证某个模型配置函数的行为。

产出：

- 一次小改动记录。
- 一次测试或手动验证记录。
